Browse the active thread workspace and its project's local sources without leaving BB. FileTree handles supported workspace file opens by default and adds a directory tree and preview pane to the thread's panel launcher, with path search, Git decorations, live updates, keyboard navigation, and saved selections.

Preview source, Markdown, images, PDF, HTML, Word documents, spreadsheets, and presentations. Toggle word wrap, refresh the preview, open the live file in your preferred editor, copy paths or contents, or save a verified copy.

Workspace operations are read-only. File attachments are not included. It carries native addons for macOS (arm64 and x64), Linux (x64 and arm64) and Windows x64; on any other host it says it can't browse that machine.
