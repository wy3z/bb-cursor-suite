## Composer

The prompt box becomes a rounded, opaque row in the style of Cursor: the
paperclip on the left, then the permission mode, model and reasoning level as
plain text, and a round send button. Once the draft wraps or has an
attachment, the controls move to a bottom row. The project and environment sit
under the box on the left, the context ring on the right. The send options
menu opens by right-clicking the send button.

The restyle is on whenever the plugin is. It restyles BB's own composer
rather than replacing it, so BB's composer fixes keep arriving.

## Agent pills

On by default. The full-width cards above the composer become one row of
small pills:

- **Agents** for child threads and background tasks, with a tray to answer,
  stop or open them.
- **Changes** for the checkout's uncommitted changes, with commit, push and
  pull request buttons.
- Workflow, plan mode, goal, to-dos, model fallback, queued messages,
  archived thread and machine status, each with its own actions.

Turn the pills off under Settings, Plugins, Agent Pills to get BB's own
cards back. The composer keeps its restyle either way.
